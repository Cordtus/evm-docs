# RPC Type Definitions

This section documents the Go types and data structures used in the Cosmos EVM JSON-RPC implementation.

## Core Types

### BlockNumber

Represents a block number or special block identifier:

```go
type BlockNumber int64

const (
    EthPendingBlockNumber  = BlockNumber(-2)
    EthLatestBlockNumber   = BlockNumber(-1)
    EthEarliestBlockNumber = BlockNumber(0)
)
```

Special values:
- `"latest"` - The most recent block
- `"earliest"` - The genesis block
- `"pending"` - Pending block with uncommitted transactions
- `"finalized"` - The most recent finalized block
- `"safe"` - The most recent safe head block

### RPCTransaction

Represents a transaction in RPC format:

```go
type RPCTransaction struct {
    BlockHash        *common.Hash         `json:"blockHash"`
    BlockNumber      *hexutil.Big         `json:"blockNumber"`
    From             common.Address       `json:"from"`
    Gas              hexutil.Uint64       `json:"gas"`
    GasPrice         *hexutil.Big         `json:"gasPrice"`
    Hash             common.Hash          `json:"hash"`
    Input            hexutil.Bytes        `json:"input"`
    Nonce            hexutil.Uint64       `json:"nonce"`
    To               *common.Address      `json:"to"`
    TransactionIndex *hexutil.Uint64      `json:"transactionIndex"`
    Value            *hexutil.Big         `json:"value"`
    Type             hexutil.Uint64       `json:"type"`
    // EIP-1559 fields
    GasFeeCap        *hexutil.Big         `json:"maxFeePerGas,omitempty"`
    GasTipCap        *hexutil.Big         `json:"maxPriorityFeePerGas,omitempty"`
    // EIP-2930 fields
    Accesses         *ethtypes.AccessList `json:"accessList,omitempty"`
    ChainID          *hexutil.Big         `json:"chainId,omitempty"`
    // Signature values
    V                *hexutil.Big         `json:"v"`
    R                *hexutil.Big         `json:"r"`
    S                *hexutil.Big         `json:"s"`
}
```

### AccountResult

Result structure for `eth_getProof`:

```go
type AccountResult struct {
    Address      common.Address  `json:"address"`
    AccountProof []string        `json:"accountProof"`
    Balance      *hexutil.Big    `json:"balance"`
    CodeHash     common.Hash     `json:"codeHash"`
    Nonce        hexutil.Uint64  `json:"nonce"`
    StorageHash  common.Hash     `json:"storageHash"`
    StorageProof []StorageResult `json:"storageProof"`
}

type StorageResult struct {
    Key   string       `json:"key"`
    Value *hexutil.Big `json:"value"`
    Proof []string     `json:"proof"`
}
```

### FeeHistoryResult

Result structure for `eth_feeHistory`:

```go
type FeeHistoryResult struct {
    OldestBlock  *hexutil.Big     `json:"oldestBlock"`
    Reward       [][]*hexutil.Big `json:"reward,omitempty"`
    BaseFee      []*hexutil.Big   `json:"baseFeePerGas,omitempty"`
    GasUsedRatio []float64        `json:"gasUsedRatio"`
}
```

## Event Types

### ParsedTx

Represents a parsed transaction from events:

```go
type ParsedTx struct {
    MsgIndex   int
    Hash       common.Hash
    EthTxIndex int32
    GasUsed    uint64
    Failed     bool
}
```

### EventFormat

Enumerates different event formats for backward compatibility:

```go
type EventFormat int

const (
    eventFormatUnknown EventFormat = iota
    eventFormat1
    eventFormat2
)
```

## Notes

- All numeric types use `hexutil` encoding for JSON marshaling
- Addresses are represented as `common.Address` from go-ethereum
- Hash values use `common.Hash` for type safety
- Optional fields in responses use pointers to distinguish between zero values and missing fields
