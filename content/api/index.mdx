# API Reference

Cosmos EVM implements a comprehensive JSON-RPC API compatible with Ethereum, allowing developers to interact with the blockchain using familiar tools and libraries.

## Available Namespaces

- **[eth](/api/eth)** - Standard Ethereum JSON-RPC methods for interacting with the blockchain
- **[net](/api/net)** - Network-related methods for checking node connectivity
- **[web3](/api/web3)** - Utility methods including SHA3 hashing and client version
- **[types](/api/types)** - Go types used by the RPC implementation

## Quick Start

You can interact with the API using standard JSON-RPC calls:

```bash
curl -X POST --data '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}' \
  -H "Content-Type: application/json" \
  http://localhost:8545
```

## Standard Compliance

Our API follows the [Ethereum JSON-RPC specification](https://ethereum.org/en/developers/docs/apis/json-rpc/), with some Cosmos-specific extensions and modifications.
