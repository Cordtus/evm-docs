# Web3 Namespace (web3_)

The `web3_` namespace provides utility methods for Web3 interactions.

## Available Methods

### web3_clientVersion

Returns the current client version in Web3 user agent format.

**Parameters:** None

**Returns:** `STRING` - Client version string

**Example:**
```bash
curl -X POST --data '{"jsonrpc":"2.0","method":"web3_clientVersion","params":[],"id":1}' http://localhost:8545
```

**Response:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "cosmos-evm/v1.0.0"
}
```

### web3_sha3

Returns the Keccak-256 hash of the given input.

**Parameters:**
1. `DATA` - The data to hash

**Returns:** `DATA` - The Keccak-256 hash

**Example:**
```bash
curl -X POST --data '{"jsonrpc":"2.0","method":"web3_sha3","params":["0x68656c6c6f20776f726c64"],"id":1}' http://localhost:8545
```

**Response:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x47173285a8d7341e5e972fc677286384f802f8ef42a5ec5f03bbfa254cb01fad"
}
```

## Notes

- The `web3_sha3` method is a pure utility function that doesn't interact with the blockchain
- These methods are implemented for compatibility with standard Web3 tools
