# Cosmos EVM Protocol

This section provides a technical overview of the Cosmos EVM protocol architecture, explaining how the Ethereum Virtual Machine is integrated with the Cosmos SDK.

## Architecture Overview

Cosmos EVM combines the robust smart contract capabilities of Ethereum with the scalability and interoperability of the Cosmos ecosystem.

### Key Components

1. **EVM Module**: The core component that implements the Ethereum Virtual Machine
2. **Cosmos SDK**: The underlying framework for building blockchain applications
3. **Tendermint Core**: Provides Byzantine Fault Tolerant consensus
4. **IBC Protocol**: Enables cross-chain communication
