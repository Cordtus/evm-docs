# Develop on Cosmos EVM

This section guides you through developing smart contracts and dApps on Cosmos EVM.

## Development Environment

Setting up your local environment for Cosmos EVM development.

<Steps>
### Install Dependencies

First, ensure you have the following tools installed:

```bash
# Install Node.js and npm
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# Install Yarn
npm install -g yarn

# Install Hardhat
yarn global add hardhat
```

### Configure Hardhat for Cosmos EVM

Create a new Hardhat project:

```bash
mkdir my-cosmos-project
cd my-cosmos-project
yarn init -y
yarn add --dev hardhat @nomicfoundation/hardhat-toolbox
npx hardhat init
```

Update your `hardhat.config.js` to include Cosmos EVM network:

```js
module.exports = {
  solidity: "0.8.19",
  networks: {
    cosmos_evm: {
      url: "https://evm-rpc.cosmos.network",
      accounts: process.env.PRIVATE_KEY ? [process.env.PRIVATE_KEY] : [],
      chainId: 9000, // Replace with actual chain ID
    },
  },
};
```

### Write Your First Contract

Create a simple contract in `contracts/CosmosGreeter.sol`:

<CodeCollapse language="solidity" maxVisibleLines={8}>
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract CosmosGreeter {
    string private greeting;
    
    constructor(string memory _greeting) {
        greeting = _greeting;
    }
    
    function greet() public view returns (string memory) {
        return greeting;
    }
    
    function setGreeting(string memory _greeting) public {
        greeting = _greeting;
    }
}
```
</CodeCollapse>

### Deploy to Cosmos EVM

Deploy your contract:

```bash
npx hardhat run scripts/deploy.js --network cosmos_evm
```
</Steps>
