# Welcome to Cosmos EVM

Seamlessly run Ethereum smart contracts on the Cosmos network, combining the best of both ecosystems.

## What is Cosmos EVM?

Cosmos EVM is a Cosmos SDK module that enables full Ethereum Virtual Machine compatibility within the Cosmos ecosystem.

Cosmos EVM combines the security and interoperability of the Cosmos SDK with the rich smart contract ecosystem of Ethereum. This integration allows developers to:

- Deploy existing Ethereum smart contracts without modifications
- Use standard Ethereum tools like Metamask, Hardhat, and Truffle
- Benefit from Cosmos features like Interchain Accounts (ICA)
- Achieve significantly higher throughput than Ethereum mainnet
