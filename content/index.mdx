# Welcome to Cosmos EVM Documentation

The Ethereum Virtual Machine on Cosmos - bringing fast, reliable, and scalable EVM compatibility to the Cosmos ecosystem.

## Key Features

- **Ethereum Compatibility**: Use existing Ethereum tools, libraries, and smart contracts
- **High Performance**: Fast block times and high transaction throughput
- **Low Fees**: Efficient consensus mechanism resulting in lower transaction costs
- **Interoperability**: Connect with other chains in the Cosmos ecosystem via IBC
- **Security**: Built on Cosmos SDK with proven security features
